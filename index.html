Publications
LAMaS
Learning Latency-Aware Orchestration for Multi-Agent Systems
Xi Shi, Mengxin Zheng, Qian Lou
NeurIPS 2026 (Main Track)
arXiv  /  Code

A latency-aware orchestration framework for multi-agent LLM systems. LAMaS learns execution graphs via constrained optimization with critical-path-aware credit assignment, plus a lightweight runtime controller that prunes redundant agent calls, cutting end-to-end latency by over 50% on four benchmarks at competitive or better accuracy.

KVShare
Arena
KVShareArena: KV-Cache Reuse Across Contexts and Model Checkpoints
Xi Shi, Mengxin Zheng, Qian Lou
Under review at ICLR 2027
arXiv  /  Code

An open benchmark for reusing KV caches when the preceding context or the model checkpoint changes (RAG, multi-agent pipelines). It compares 11 repair and compression methods under one protocol across 5 dense and MoE LLMs, showing that repairs cut time-to-first-token by 81–94% and that trained adapters degrade across checkpoints unless retrained.

Safe
Routing
Learning to Route Safely in Multi-Agent LLM Systems
Xi Shi, Qian Lou
Under review, 2026

A constrained reinforcement learning framework whose adaptive Lagrangian router jointly selects collaboration topology, agent roles, and LLM assignments, improving jailbreak resistance and robustness to malicious agents under an explicit clean-accuracy floor.
